## Trabalho realizado

### 1. Análise do CLAUDE.md
Foram identificados três grupos de problemas:

- **Erros de digitação**: `GESTÂO`→`GESTÃO`, `PROPOSITO`→`PROPÓSITO`, `Framwwork`→`Framework`, `operaciona`→`operacional`, `Architeture`→`Architecture`, `tranferencias`→`transferências`, `vamso`→`vamos`.
- **Inconsistência relevante**: nome da pasta de histórico aparecia como `.histórico` (com acento) e `.historico` (sem acento) — duas pastas diferentes para o sistema de arquivos.
- **Lacunas de decisão**: padrão de UI, estrutura de camadas, framework de testes, tratamento de câmbio e idioma do commit não estavam definidos.

### 2. Decisões tomadas
- **Padrão de UI**: MVVM.
- **Testes unitários**: xUnit.
- **Camadas** (nomes em inglês, prefixo `GEF`): `GEF.Domain`, `GEF.Application`, `GEF.Infrastructure`, `GEF.UI`, `GEF.Tests`.
- **Código de negócio** (classes/métodos/variáveis): permanece em português Brasil.
- **Câmbio**: cotação informada manualmente para começar (evolução futura via API registrada como possibilidade).
- **Commit**: mensagens em português.
- **Pasta de histórico**: padronizada como `.historico` (sem acento).
